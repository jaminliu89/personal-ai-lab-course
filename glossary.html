GLOSSARY

零基础术语表

Base Model

主要完成预训练、尚未或较少做指令对齐的基础模型。

Instruct Model

经过指令微调/对齐，更适合对话和遵循要求。

Token

Tokenizer 处理文本后的基本离散单位。

Context Window

单次推理可处理的 token 上限范围。

Parameter

模型训练中被学习的数值权重。

Inference

只进行前向计算，使用模型生成结果。

Training

计算 loss、梯度并更新参数。

SFT

Supervised Fine-Tuning，有监督指令微调。

LoRA

冻结大部分基础权重，只训练低秩适配参数。

QLoRA

量化基础模型 + LoRA 的低显存微调方式。

Gradient

Loss 对参数的导数/变化方向信息。

Learning Rate

优化器每一步更新幅度的重要超参数。

Epoch

完整遍历一遍训练集。

Batch

一次训练 step 同时处理的一组样本。

Checkpoint

训练过程中保存的模型/优化器等状态。

Eval

用固定数据和指标评估模型。

DPO

利用偏好对直接进行偏好优化的一类方法。

RAG

检索外部资料加入上下文，不直接修改模型权重。

Agent

让模型结合状态、工具与循环执行多步骤任务的系统。

Quantization

用更低精度表示权重/激活等以节省资源。
